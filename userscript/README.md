# B 站导入桥（本机下载后上传）

当前应用使用 `wangke-bili-bridge.user.js` **3.0 及以上**。安装 Tampermonkey 后，从应用设置或 B 站导入弹窗的「安装 / 更新油猴脚本」进入，授权扩展在应用站点运行并刷新页面。Chrome / Edge 还需开启“允许用户脚本”。

在同一个浏览器登录 B 站，再到应用资料库粘贴链接、选择集数与字幕。解析、字幕获取和音视频下载走本机网络；浏览器合并后上传服务器。**上传完成前请保持页面打开**。无字幕时，上传完成后由服务器转写。
脚本仅使用 B 站 API 的浏览器登录态，不提供 Cookie 导出接口；字幕/CDN 请求不携带 Cookie。应用不向服务器发送 Cookie 或签名下载地址，不自动回退到服务器出口。旧的手动保存 Cookie 可在设置中清除。
脚本请求限制在必要的 B 站接口与 CDN，支持进度、取消、超时及大小限制。不支持扩展的浏览器或独立 PWA 请使用支持油猴的浏览器标签页，或上传自行下载的视频。其它旧脚本仅供历史参考，不要与此脚本同时启用。使用方式与限制见根目录 [README](../README.md#导入-b-站视频)。
